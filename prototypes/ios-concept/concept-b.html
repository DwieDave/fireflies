Concept B · machine map and dock

Home is the machines, each with its spaces drawn as tiny layouts. A five-place dock at the bottom (machines, fireflies, alerts, mods, hosts) is always there except inside a terminal. Travel is machine › space › pane, like a file browser; the dock jumps between kinds of thing.

gains: the phone mirrors how the Mac is arranged, so finding "the db pane in platform on homelab" is direct; mods are first-class places, not sheets; easy to learn (a tab bar is what iOS hands expect). costs: agents needing you sit behind a dock tab and a badge rather than on the first screen; less of the sky, so it reads more like a tool than like nocturne; the dock takes 84 px from every screen.
