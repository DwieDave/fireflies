Kit batch 1 is merged on integrate (green). Merge integrate, then swap your local stand-ins. All from "@fireflies/kit"; test layers from "@fireflies/kit/testing"; Live includes HcLive. docs/effect-mods.md has each piece.
(a) Lists and maps: a Schema combinator, no separate list/map keys: listOf(item) and mapOf(entry) (an entry of another shape is left out, not the whole value; mapOf reads an object as a ReadonlyMap and writes it back as an object). guard.ts maps: sharedListKey(n,g)/readSharedList -> sharedKey(n, listOf(S)) / readShared(shared, KEY, []); sharedMapKey/readSharedMap -> sharedKey(n, mapOf(S)) / readShared(shared, KEY, new Map()); writeSharedMap -> writeShared(setShared, KEY, map) (false, nothing written, if an entry cannot encode); parseJsonMap(text,g) -> decodeJsonOption(mapOf(S))(text), in an effect decodeJson(mapOf(S), what); in an effect Shared.get(KEY) / Shared.set(KEY, map). There is no Shared.getList/getMap.
(b) hc: its own service Hc { run(args): Effect<ExecResult, ExecError> }; hcOk(args): Effect<string, ExecError | ExitError, Hc>; hcJson(schema, what)(args) (pass "--json" in args); hcService(run) for a library handed hc; testing: hcTest(handler) -> { layer, calls }.
(c) Workspace gains agents: Effect<AgentInfo[]> and focused: Effect<Option<{ space, tab, pane, terminal, shown, agent, cwd, block }>>; workspaceTest({ agents?, focused? }).
(d) Files.list(dir): Effect<Option<readonly string[]>, FileError> (sorted names; none when the folder is not there); filesTest(files?, folders?).
(e) The folder for a pane opened without one is ONE kit function now: here: Effect<Here, never, Workspace>; hereOf({ spaces: spaces(), panes: panes(), focused: focused() }) for a render; Here { folder: Option<string>; on: string | null }. Drop your mod own version (scripts/here.ts was the first; finder, file-tree, git, github, databases have theirs).
(f) Local dates: localTime(ms) -> { year, month 1-12, day, hours, minutes, seconds, weekday, offset }; localStamp(ms, { seconds?, zone? }) -> "2026-11-16 14:05": no mod prints with Date.
Also merged: @fireflies/viewer no longer sticks on Reading under load (heads sized per kind, sliced parsing, a watchdog that says "Can't show it: reading it was cut off…").
