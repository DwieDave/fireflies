# Security

Report vulnerabilities privately through [GitHub's Report a vulnerability](https://github.com/DwieDave/fireflies/security/advisories/new). Don't post exploit details in a public issue.

Include the Fireflies version (and its commit), OS, what you found, steps to reproduce it, and the impact. A small proof of concept helps. Remove secrets and personal data from logs.

Only the latest commit on `main` is supported. A vulnerability that Herdr has too belongs with [Herdr](https://github.com/herdrdev/herdr-app/security/advisories/new) as well.

For how Fireflies handles trusted mods, updates and privacy, see [security and privacy](docs/security.md).
